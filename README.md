# Bloom & Co. Flower Shop

A responsive front-end flower shop built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive desktop and mobile layout.
- Flower catalog with visible prices.
- Category filters and price sorting.
- Interactive shopping bag with subtotal and remove controls.
- Custom bouquet form with an on-page preview message.
- Small animations and hover interactions.

## Open in Visual Studio Code
1. Download and extract this folder.
2. In VS Code, choose **File → Open Folder** and select `bloom_and_co`.
3. Open `index.html` in a browser, or install the Live Server extension and choose **Open with Live Server**.

No Python, framework, or package installation is needed.

## Important before publishing
- Replace the sample shop story and contact email with your own details.
- Confirm the flower names and prices.
- The photos load from Unsplash, so an internet connection is needed for them.
- The shopping bag is a demonstration only. It does not process payments or real orders.
